信号的多普勒展缩建模

从收发双方相对运动产生的传播时延变化出发，推导信号的多普勒时间展缩模型，并讨论其连续时间表达与离散采样实现。

在“狭义相对论”的物理学假设下，光速是恒定的，是任何物体运动速度的上限。因此，信号在发送时刻就已经确定了其传播方向与传播距离，与后续收发机的运动无关。

假设发送机从 t0t_0t0​ 时刻开始，每隔 TsT_sTs​ 时间间隔，离散地发送一次复信号。t0t_0t0​ 时刻，接收机在距离发送机 D0D_0D0​ 的位置，并且以一定的速度 vvv 远离发送机运动。

感觉本文最初的假设，发送机在 t0t_0t0​ 时刻发送的信号，其传播距离仅与 D0D_0D0​ 有关，假设接收机在 t0+τ0t_0+\tau_0t0​+τ0​ 时刻收到该信号，则 τ0=D0c\tau_0=\dfrac{D_0}{c}τ0​=cD0​​，表示传输时延。

发送机在 t0+Tst_0+T_st0​+Ts​ 时刻发送信号，此时二者的距离为 D0+v⋅TsD_0+v\cdot T_sD0​+v⋅Ts​，传输时延为 τ1=D0+v⋅Tsc\tau_1=\dfrac{D_0+v\cdot T_s}{c}τ1​=cD0​+v⋅Ts​​，接收机收到信号的时刻为 t0+Ts+τ1t_0+T_s+\tau_1t0​+Ts​+τ1​，以此类推，第 nnn 个复信号的传输时延为

τn=D0+v⋅nTsc\tau_n = \dfrac{D_0+v\cdot nT_s}{c}\\ τn​=cD0​+v⋅nTs​​

接收机接收到第 nnn 个复信号的时刻为

t0+nTs+τn=t0+nTs+D0+v⋅nTsct_0 + nT_s + \tau_n = t_0 + nT_s + \dfrac{D_0+v\cdot nT_s}{c}\\ t0​+nTs​+τn​=t0​+nTs​+cD0​+v⋅nTs​​

接收机收到第 nnn 个复信号与第 n−1n-1n−1 个复信号的时间差为

Ts+v⋅Tsc=(1+vc)TsT_s + \dfrac{v\cdot T_s}{c} = (1 + \dfrac{v}{c}) T_s\\ Ts​+cv⋅Ts​​=(1+cv​)Ts​

而发送机发送第 nnn 个复信号与第 n−1n-1n−1 个复信号的时间差为 TsT_sTs​，由此可以看出，经过多普勒的影响后，信号在接收端表现为 平移+展缩 的效果。
