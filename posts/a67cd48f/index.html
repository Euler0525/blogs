Flash Attention·

Flash Attention 的核心不是改变 Attention 数学公式，而是不把完整 S×SS\times SS×S 中间矩阵写回 HBM。

普通实现逻辑上可能类似：

Q,K→QKT.Q, K \rightarrow QK^T. Q,K→QKT.

把巨大的 S×SS\times SS×S 矩阵写入 GPU HBM。然后再：

HBM→Softmax\text{HBM} \rightarrow \text{Softmax} HBM→Softmax

再写回。然后：

P,V→PV.P, V \rightarrow PV. P,V→PV.

大量时间浪费在：

HBM 读写.\text{HBM 读写}. HBM 读写.

而不仅仅是 FLOPs。Flash Attention 不一次生成整个：

S×S.S\times S. S×S.

而是把 Q,K,VQ, K, VQ,K,V 切成小块。例如概念上：

只在 GPU 更快但容量更小的片上存储中保留当前 block 所需数据，例如：

  • registers；
  • shared memory / SRAM。

算完这个块后立即把贡献累积到输出。因此不需要：

完整 materialize 一个 S×S score matrix.\text{完整 materialize 一个 }S\times S\text{ score matrix}. 完整 materialize 一个 S×S score matrix.

普通 Softmax：

pj=exj∑kexkp_j = \frac{e^{x_j}} {\sum_k e^{x_k}} pj​=∑k​exk​exj​​

通常需要知道整行：

x1,…,xS.x_1,\dots, x_S. x1​,…,xS​.

而数值稳定版本还需要：

m=max⁡jxj.m =\max_jx_j. m=jmax​xj​.

然后：

pj=exj−m∑kexk−m.p_j = \frac{e^{x_j-m}} {\sum_ke^{x_k-m}}. pj​=∑k​exk​−mexj​−m​.

看起来必须一次拿到所有 SSS 个元素。

Flash Attention 使用一种 online softmax 思想分块处理时持续维护当前行的最大值和归一化因子。

假设已经处理了一部分，保存：

moldm_{\text{old}} mold​

和：

lold=∑exi−mold.l_{\text{old}} = \sum e^{x_i-m_{\text{old}}}. lold​=∑exi​−mold​.

新 block 出现新的最大值之后，可以重新缩放旧累积值，从而得到正确的新 normalization。因此无需保存整行 score，也能精确完成稳定 Softmax。事实上，Flash Attention 没有消除标准 Attention 的平方计算复杂度。Flash Attention 主要是 IO-aware exact attention，显著降低了 HBM IO 带宽从而降低显存压力。

标准 self-attention 仍然需要比较：

S×SS\times S S×S

个 Query-Key 对。所以主要计算复杂度仍然近似：

O(S2Dh).O(S^2D_h). O(S2Dh​).

多头总体近似：

O(S2H).O(S^2H). O(S2H).
