Attention 的性能瓶颈·

设单个 attention head 的

Q,K,V∈RN×d.Q, K, V\in\mathbb R^{N\times d}. Q,K,V∈RN×d.

标准 Attention 可以写成：

S=QK⊤d,P=softmax⁡(S),O=PV,S =\frac{QK^\top}{\sqrt d},\qquad P =\operatorname{softmax}(S),\qquad O = PV, S=d​QK⊤​,P=softmax(S),O=PV,

其中

S,P∈RN×N.S, P\in\mathbb R^{N\times N}. S,P∈RN×N.

从算法复杂度看，两次主要矩阵乘都需要 O(N2d)O(N^2d)O(N2d) FLOPs，因此很容易得到“Attention 慢是因为 N2N^2N2 FLOPS 计算量太大”的结论。但在真实 GPU 上，kernel 的时间不仅取决于计算量，还取决于数据在内存层次之间移动的代价。

标准实现通常经历：

Q,K→QK⊤→HBM→softmax/mask→HBM→PV.Q, K \rightarrow QK^\top \rightarrow \text{HBM} \rightarrow \text{softmax/mask} \rightarrow \text{HBM} \rightarrow PV. Q,K→QK⊤→HBM→softmax/mask→HBM→PV.

也就是说，完整的 SSS 和 PPP 往往会被 materialize 到 HBM，然后再次读回。对于长序列，这两个 N×NN\times NN×N 中间矩阵会迅速成为显存带宽和 activation memory 的主要负担。

以 A100 为例，HBM 容量很大、带宽约为 TB/s 量级，而每个 SM 的片上 SRAM 容量只有数百 KB，却拥有远高于 HBM 的带宽。于是 GPU kernel 大致可分为两类：大型 GEMM 往往具有较高 arithmetic intensity，更接近 compute-bound；softmax、mask、dropout、reduction 等操作 FLOPs 很少，但需要反复读取和写回数据，更容易 memory-bound。

对 memory-bound workload，更合理的性能模型是：

T≈Bytes transferredMemory bandwidth,T\approx \frac{\text{Bytes transferred}} {\text{Memory bandwidth}}, T≈Memory bandwidthBytes transferred​,

而不是只看 FLOPs。FlashAttention 的核心出发点正是：Attention 的主要瓶颈之一，是 N2N^2N2 中间矩阵造成的 HBM IO。

FlashAttention·

FlashAttention 的核心目标是

QK⊤ 仍然计算，但完整 S 不写入 HBM\boxed{ QK^\top\text{ 仍然计算，但完整 }S\text{ 不写入 HBM} } QK⊤ 仍然计算，但完整 S 不写入 HBM​

它把 Q,K,VQ,K,VQ,K,V 切成能够放入片上 SRAM 的 tile，在片上完成局部 score 计算、softmax、mask、dropout 和 PVPVPV 累积。局部的 SijS_{ij}Sij​、PijP_{ij}Pij​ 使用完立即丢弃，从而避免完整 N×NN\times NN×N 矩阵的 materialization。

真正困难的地方不是矩阵乘，而是 softmax。矩阵乘天然可以分块：

Tiling、Fusion 与 Backward Recomputation·

FlashAttention 的 tiling 与 kernel fusion 是同一件事的两个侧面。标准 Attention 可能跨多个 kernel 依次执行：

QK⊤→HBM→mask→HBM→softmax→HBM→dropout→HBM→PV.QK^\top \rightarrow \text{HBM} \rightarrow \text{mask} \rightarrow \text{HBM} \rightarrow \text{softmax} \rightarrow \text{HBM} \rightarrow \text{dropout} \rightarrow \text{HBM} \rightarrow PV. QK⊤→HBM→mask→HBM→softmax→HBM→dropout→HBM→PV.

FlashAttention 则把：

QiKj⊤→mask→softmax→dropout→PijVjQ_iK_j^\top \rightarrow \text{mask} \rightarrow \text{softmax} \rightarrow \text{dropout} \rightarrow P_{ij}V_j Qi​Kj⊤​→mask→softmax→dropout→Pij​Vj​

尽可能融合在同一个 kernel 的片上执行路径中。online softmax 使 tile 可以独立推进，tiling 又使 N2N^2N2 中间矩阵无需落到 HBM，从而为 aggressive fusion 创造条件。

训练时 backward 更能体现“IO 优先”的设计思路。标准 Attention backward 涉及：

dV=P⊤dO,dP=dOV⊤,dV = P^\top dO,\qquad dP = dOV^\top, dV=P⊤dO,dP=dOV⊤,

dS=P⊙(dP−rowsum⁡(P⊙dP)),dS = P\odot \left( dP-\operatorname{rowsum}(P\odot dP) \right), dS=P⊙(dP−rowsum(P⊙dP)),

以及：

dQ=dSK,dK=dS⊤Q.dQ = dSK,\qquad dK = dS^\top Q. dQ=dSK,dK=dS⊤Q.

最直接的实现会在 forward 保存完整 PPP，导致 O(N2)O(N^2)O(N2) activation memory。FlashAttention 选择不保存 PPP，而是在 backward 重新计算：

Sij=QiKj⊤,S_{ij}= Q_iK_j^\top, Sij​=Qi​Kj⊤​,

再利用 forward 保存的 normalization statistics 重建：

Pij.P_{ij}. Pij​.

因此 FlashAttention 的一个关键工程原则是：

recomputation can be cheaper than HBM access\boxed{\text{recomputation can be cheaper than HBM access}} recomputation can be cheaper than HBM access​

也就是：如果重新计算主要发生在 Tensor Core、register 和 SRAM 中，而它替代的是大量 HBM 读写，那么增加 FLOPs 反而可能缩短 wall-clock time。

Softmax backward 还有一个重要化简。定义：

Di=∑jPijdPij.D_i =\sum_jP_{ij}dP_{ij}. Di​=j∑​Pij​dPij​.

由于：

Di=Oi⋅dOi.\boxed{D_i = O_i\cdot dO_i}. Di​=Oi​⋅dOi​​.

于是局部 backward 可写成：

dSij=Pij⊙(dPij−Di),dS_{ij} = P_{ij}\odot(dP_{ij}-D_i), dSij​=Pij​⊙(dPij​−Di​),

其中 DiD_iDi​ 只需要长度 ddd 的输出与梯度即可得到，不需要保存长度 NNN 的完整 probability row。这进一步使 backward 适合 tiled execution。

复杂度·

FlashAttention 没有改变 dense attention 的主计算复杂度：

FLOPs=O(N2d).\boxed{\text{FLOPs}= O(N^2d)}. FLOPs=O(N2d)​.

它改变的是中间存储和 HBM IO。完整的 S,PS,PS,P 不再需要 materialize；额外 row-wise statistics 只需要 O(N)O(N)O(N) 规模，而必要的输入输出仍保持原本的 O(Nd)O(Nd)O(Nd)。

论文给出的 HBM IO complexity 对比为：

Standard Attention:Θ(Nd+N2),\text{Standard Attention}: \Theta(Nd+N^2), Standard Attention:Θ(Nd+N2),

FlashAttention:Θ(N2d2M),\text{FlashAttention}: \Theta\left(\frac{N^2d^2}{M}\right), FlashAttention:Θ(MN2d2​),

其中 MMM 表示可用 SRAM capacity 参数。在典型 head dimension 和合适 tile 大小时，后者显著减少 HBM traffic。

FlashAttention-2·

FlashAttention 已经解决了最严重的 HBM IO 问题，但第一版 kernel 的吞吐仍明显低于高质量 GEMM。FlashAttention-2 的 profiling 发现，新的瓶颈集中在 GPU work partitioning：thread block 数量不足、occupancy 不够、warp 分工不理想、shared-memory communication 偏多，以及 non-matmul FLOPs 的实际代价较高。

因此 FA2 的重点从：

HBM↔SRAM\text{HBM}\leftrightarrow\text{SRAM} HBM↔SRAM

继续下沉到：

SM→Thread Block→Warp→Tensor Core/Register.\boxed{ \text{SM} \rightarrow \text{Thread Block} \rightarrow \text{Warp} \rightarrow \text{Tensor Core/Register} }. SM→Thread Block→Warp→Tensor Core/Register​.

这使大量 SM 更容易保持忙碌。

Forward 适合 row-oriented parallelism，因为每个 QiQ_iQi​ 可以独立遍历所有 K/V blocks 并最终生成自己的 OiO_iOi​。Backward 的依赖更复杂：为了高效计算 dK,dVdK,dVdK,dV，FA2 可以采用 column-oriented work partition，而多个 worker 对同一 dQidQ_idQi​ 的贡献需要累积，因此会引入 atomic add。这里的关键不是保持 forward/backward 形式对称，而是让 schedule 服从数据依赖。

Warp Work Partitioning·

增加 thread-block 数量解决的是 block-level parallelism，FA2 还进一步优化一个 block 内多个 warp 的分工方式。

FA1 forward 的典型方案可以理解为 Split-K：多个 warp 共享同一组 Q rows，而把 K/V 方向上的工作拆开。这样在 PVPVPV 阶段，不同 warp 会得到同一组 output rows 的 partial contribution：

O=O(1)+O(2)+⋯ .O = O^{(1)}+O^{(2)}+\cdots. O=O(1)+O(2)+⋯.

于是需要把 partial results 写入 shared memory、同步、重新读取并 reduction。真正昂贵的不是几次加法，而是：

warp-to-warp communication through shared memory.\boxed{ \text{warp-to-warp communication through shared memory} }. warp-to-warp communication through shared memory​.

FA2 改为 Split-Q。把 Q rows 在 warp 之间切分：

Q=[Q(1)Q(2)Q(3)Q(4)],Q = \begin{bmatrix} Q^{(1)}\\ Q^{(2)}\\ Q^{(3)}\\ Q^{(4)} \end{bmatrix}, Q=​Q(1)Q(2)Q(3)Q(4)​​,

而 K/V 对这些 warp 可复用。每个 warp 负责独立的一部分 output rows：

Q(w)K⊤→O(w).Q^{(w)}K^\top \rightarrow O^{(w)}. Q(w)K⊤→O(w).

最终输出是拼接：

O=[O(1)O(2)O(3)O(4)],O = \begin{bmatrix} O^{(1)}\\ O^{(2)}\\ O^{(3)}\\ O^{(4)} \end{bmatrix}, O=​O(1)O(2)O(3)O(4)​​,

而不是多个 partial output 的求和，因此不需要 warp 间 reduction。

这体现了一个很通用的 GPU kernel 原则：

尽量让一个 worker 拥有最终 output，而不是共同拥有 partial output.\boxed{ \text{尽量让一个 worker 拥有最终 output，而不是共同拥有 partial output} }. 尽量让一个 worker 拥有最终 output，而不是共同拥有 partial output​.

后者通常意味着更多 synchronization、shared-memory traffic 和 reduction。

Tile Size 与 Causal Attention·

FlashAttention 并不是 tile 越大越好。增大 Br,BcB_r,B_cBr​,Bc​ 可以提高数据复用、减少某些访问，但同时会提高 register pressure 和 shared-memory usage，可能降低 occupancy；严重时还会发生 register spilling，甚至超过 shared-memory capacity。

因此实际调优必须同时考虑：

HBM IO+SRAM traffic+register pressure+occupancy+Tensor Core utilization.\boxed{ \text{HBM IO} + \text{SRAM traffic} + \text{register pressure} + \text{occupancy} + \text{Tensor Core utilization} }. HBM IO+SRAM traffic+register pressure+occupancy+Tensor Core utilization​.

Causal Attention 还可以利用 tile 结构进一步减少无效计算。对于：

Sij=−∞,j>i,S_{ij}=-\infty,\qquad j > i, Sij​=−∞,j>i,

如果一个 tile 完全位于 causal mask 的上三角区域，那么整个 tile 都不会贡献输出，可以直接跳过，不必计算 QiKj⊤Q_iK_j^\topQi​Kj⊤​。只有跨越主对角线的 tile 才需要进行 elementwise masking。这里 tiling 的价值已经不只是改善内存访问，它还把结构化条件从 element level 提升到了 block level。

标准 Attention 中，大量 N2N^2N2 materialization 让 pipeline 存在严重 memory-bound 部分。FA1 通过减少 bytes transferred 提高有效 arithmetic intensity，使 workload 更接近 compute-bound。到了这个阶段，新的问题才暴露出来，计算单元是否真的被充分利用？FA2 因此继续优化 occupancy、thread-block parallelism、warp-level work partition、shared-memory communication 和 non-matmul FLOPs。

总结·

FlashAttention 的突破，不是发明了新的 Attention 数学形式，而是重新安排 exact attention 的执行顺序。通过 tiling、online softmax、kernel fusion 和 backward recomputation，它避免把完整的 S,P∈RN×NS,P\in\mathbb R^{N\times N}S,P∈RN×N materialize 到 HBM，从而显著降低 HBM IO 和 activation memory。

FlashAttention-2 则进一步认识到，当 IO 瓶颈被缓解后，性能会转而受 GPU 并行映射限制。于是它减少 inner loop 中的 non-matmul FLOPs，引入 sequence-level thread-block parallelism，并将 warp work partition 从 Split-K 改成 Split-Q，减少 shared-memory communication，提高 occupancy 和 Tensor Core utilization。

因此，FlashAttention 系列真正展示的是一条完整的 algorithm-hardware co-design 路径：

Algorithm→Memory Hierarchy→Kernel→Thread Block→Warp→Tensor Core.\boxed{ \text{Algorithm} \rightarrow \text{Memory Hierarchy} \rightarrow \text{Kernel} \rightarrow \text{Thread Block} \rightarrow \text{Warp} \rightarrow \text{Tensor Core} }. Algorithm→Memory Hierarchy→Kernel→Thread Block→Warp→Tensor Core​.

高性能 Attention 的关键不只是“算多少”，而是同时设计：数据放在哪里、什么时候搬、以什么粒度计算、由谁计算，以及中间结果是否值得保存。
